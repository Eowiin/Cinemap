À propos

Vie privée

Cinemap ne dépose aucun cookie et ne demande aucun compte.

  • Mesure d'audience anonyme : le site compte, par jour, les pages vues et quelques actions (réserver, ajouter une séance). Aucune adresse IP ni aucun identifiant n'est enregistré avec ces compteurs. Si votre navigateur active Global Privacy Control, rien n'est compté.
  • Favoris et programme : gardés seulement dans votre navigateur. Le serveur ne reçoit que ce qu'il faut pour répondre à une recherche (par exemple vos cinémas favoris pour filtrer les séances), sans le conserver.
  • Position : envoyée avec la recherche pour trouver les cinémas proches, jamais conservée ; arrondie à ~100 m pour afficher le nom de votre ville (service de l'IGN).
  • Journaux du serveur : comme tout site, le serveur web note l'adresse IP et la page demandée, pour le fonctionnement et la sécurité. Ils sont effacés au bout de 14 jours.

Sources et crédits

  • Séances : AlloCiné, mises à jour chaque nuit. Vérifiez l'horaire sur le site du cinéma avant de partir.
  • Données des films (images, bandes-annonces, notes) : TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.
  • Carte : OpenFreeMap, © contributeurs OpenStreetMap (ODbL).
  • Salles de cinéma : données du CNC ; positions : API Adresse (Base Adresse Nationale).
